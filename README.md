# Хороший адвокат

Интерактивный прототип стратегического юридического триллера: ноутбук с делами, новостями и почтой; телефон с детективами и банком.

Играть: https://mikhalevaleksei.github.io/good-lawyer-prototype/

Публикация: https://github.com/MikhalevAleksei/good-lawyer-prototype/actions

## Возможности

- Четыре связанных дела и доступ к ним по известности.
- Предложения клиентам, согласия и отказы.
- Два контакта, законные и незаконные поручения.
- Оплата агентов, гонорары и история банковских операций.
- Восьмисекундная судебная сцена, сроки подготовки и исходы дел.
- Расследование против адвоката, независимая защита, штраф и тюремный финал.
- Одновременное отображение двух устройств на компьютере и переключение на телефоне.

## Локальный запуск

Требуются Python 3.10+ и Node.js для проверки синтаксиса.

```sh
python3 scripts/build.py
python3 scripts/check_site.py
python3 -m http.server 8080 --directory site
```

Открыть http://localhost:8080/. Сценарий кампании доступен в `site/scenario.html`.

## GitHub Actions

Каждое обновление `main` собирает и проверяет статические страницы, затем публикует каталог `site` в GitHub Pages. Можно запустить workflow вручную из Actions. Источник Pages — GitHub Actions.

Исходный интерфейс находится в `source/interface.html`. Браузерная версия собирается без внешних библиотек или сетевых API. Изображение интерфейса — визуальный концепт; точные правила заданы в прототипе и сценарии. Игровые юридические процессы вымышлены.
